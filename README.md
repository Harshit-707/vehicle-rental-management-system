# vehicle-rental-management-system
Vehicle Rental Management System (Python, OOP)

VEHICLE RENTAL MANAGEMENT SYSTEM (PS No. 66)

- Simple Python 3 console program for a vehicle rental shop
- Uses OOP with two classes: Vehicle and Rental
- Uses a list (all vehicles) and a dictionary (rental details)
- Add vehicles, rent a vehicle, return it, and view available vehicles
- Bill = rate per day x days, with 10% discount for 7 or more days
- A vehicle that is already rented cannot be rented again
- All data is saved in vehicles.txt using file handling
- Run with: python one.py
